# Gratikey 🌿

Gratikey is a Flutter-based wellness and mindfulness application designed to help users improve their daily mental wellness through breathing exercises, guided sessions, gratitude journaling, personal reflections, and community interaction.

The application provides a smooth and engaging experience with organized features, reusable components, and a scalable Flutter architecture.
